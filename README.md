# OnlyX Browser

The operator's desktop browser: **app.onlyx.ai in tabs**, and a tab for each connected creator's
OnlyFans — opened through **her** network and wearing **her** device, never yours.

This repository holds the installers only. The source is private.

## Install (macOS)

1. Download the `.dmg` from the [latest release](../../releases/latest).
2. Open it and drag **OnlyX Browser** to **Applications**.
3. Open it from Applications.
4. Press **Sign in with your browser** — your own browser opens, you approve there, and the app
   takes it from here. Nothing is ever typed into the app.

The app is signed with a Developer ID and notarized by Apple, so it opens without a warning.
If macOS ever says the app "cannot be opened", you have an unsigned copy — delete it and download
again from the link above.

## Creator tabs, and the one rule

Press **+** and choose a connected creator. Her OnlyFans opens already signed in.

**While any tab for a creator is open, her seat is held** — OnlyX does not answer her fans, the
sync pauses, follow-ups wait. You are the one operating her account for that time. Close her last
tab and the seat resumes within seconds, on the session exactly as you left it.

You can open several tabs on the same creator; they share her session and her hold.

## Add an account, or reconnect one

Both go through the OnlyX console and the **OnlyX Login** app — a different creator uses *Add
account*, the same creator uses *Reconnect*.

## Updates

The app checks this repository and updates itself. No action needed.
